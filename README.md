# Pipe factory demo

A demo dashboard built on **made-up** spreadsheet data for a factory that makes PP-R/PE-RT hybrid water pipe.
It shows what happens when five spreadsheets (recipes, purchases, production, sales, stock counts) are cleaned
into one database and checked against each other: material used above the recipe, stock missing at count, supplier
price gaps, margin erosion, discount leakage and duplicate entries.

Open `index.html` (or the GitHub Pages site for this repo). No real company's data is used.
